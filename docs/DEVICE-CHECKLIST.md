# 真機與人工檢查表

這些項目**都還沒有人實測**。桌面瀏覽器的模擬結果不能填在這裡。每一項請記下裝置型號、系統與瀏覽器版本、日期、結果與問題。

## 準備

1. `npm run build`，把 `dist/` 放到一個 **HTTPS** 測試網址。手機用區網 `http://192.168.x.x` 開啟不是安全來源，service worker 不會註冊，無法驗收離線與安裝。
2. 測試用虛構問題，不要輸入真實私密內容。
3. 固定例題：四母象依序為少年 Puer、龍首 Caput Draconis、悲傷 Tristitia、白 Albus。正確結果是裁判「交會 Conjunctio（2112）」、第 10 宮「大幸運 Fortuna Major（2211）」，全部 16 位見 `fixtures/teaching.json`。

## 選用 AI 的真實 API 驗證（尚未執行）

由願意負擔 API 費用的金鑰持有人，以虛構問題操作；送出前核對畫面預覽。記錄日期、所選模型、是否成功、錯誤類別與取消後狀態，不記下金鑰或私人內容。

| 操作 | 預期 | 結果 |
|---|---|---|
| 不勾選問題，預覽後請 AI 轉述 | 只傳預覽的盤面與解讀；回覆顯示引用查核結果，保存並重開可見 | |
| 使用無效金鑰；遇到婉拒或服務錯誤時保留錯誤類別 | 有可理解的錯誤，原盤與日誌不變，不冒稱保存成功 | |
| 在等待回覆時取消，再離線使用一般解讀 | 取消不新增 AI 回覆，核心功能可繼續使用 | |

自動測試攔截的 API 回覆不能填成這裡的真實 API 驗收；沒有遇到的婉拒或服務錯誤仍標待驗證。
