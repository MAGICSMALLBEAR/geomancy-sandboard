# 第一版驗收清單

本文件是待建 App 的驗收要求，**不是已通過的測試報告**。本次已通過項目只列於 [STATUS](../STATUS.md)。代理執行時在 STATUS 記日期、命令／裝置、結果與證據，不可把本清單的預期結果當成實測結果。

## 2. 五條必要端到端流程

**P01 新手點沙**：首頁→輸入 fixture 的工作問題→選第 10 宮→點沙依 fixture 16 個原始數量輸入→完成→略過動畫→查看 J、N2→展開證據→寫筆記→日誌重開。核對全部圖式與同一 ID。

**P02 中斷恢復**：做完 5 列，第 6 列點三下但不完成→刷新→前 5 列存在、第 6 列為空且有提示→做完剩餘列→僅一筆日誌。

**P03 快速與保存失敗**：注入固定 bytes 和一次寫入失敗→連按起卦→出現未保存提示→重試→同 bytes 同盤→刷新同結果。測試注入只存在於測試環境，正式 UI 沒有操作亂數的 debug 按鈕。

**P04 資料往返**：以手動四母完成→寫一段繁體中文筆記→匯出→乾淨瀏覽器 context 匯入→核對所有原始資料與文字→再匯入不重複→把 JSON 其中一個 D 位改掉，應拒絕。

**P05 離線**：production build 線上首次載入→等待 worker 控制與離線可用提示→斷網→關閉再重新打開 App→新起一盤→閱讀解讀與十六象→加入筆記→匯出→恢復網路。外部來源頁不要求離線可開，App 主流程必須可用。

## 3. 裝置與可近用人工驗收

| 環境 | 核心項目 | 結果紀錄 |
|---|---|---|
| Windows Chrome／Edge，滑鼠＋鍵盤 | 360/768/1440 px、200% 縮放、完整流程 | 填版本、截圖與問題 |
| macOS Safari（可取得時） | 瀏覽、儲存、下載 JSON、重開 | 無裝置就標待驗證 |
| Android Chrome 真機 | 多點觸控、捲動、旋轉、背景、安裝與離線 | 型號／OS／瀏覽器 |
| iPhone Safari 真機 | 點沙、防誤觸、軟鍵盤、加入主畫面、離線重開 | 型號／iOS／瀏覽器 |
| 鍵盤／讀屏 | 焦點順序、加入一點替代、對話框、盤位文字 | 工具與結果 |
| 系統減少動態效果 | 不播放大幅粒子移動；不影響結果 | 設定與流程 |

Playwright 的 WebKit 可補測相容性，但不是 iPhone 真機，也不等於真正 Safari 安裝流程。缺少裝置時交測試腳本，不將「待驗證」寫成「通過」。

視覺檢查：正文對比至少 4.5:1；操作目標 44 px；沙盤之外可捲頁；底部按鈕不被鍵盤遮住；長問題、長拉丁名、錯誤提示和空列表不溢出；概覽很小時仍有可點的列表。

## 4. 發布前的門檻

阻擋試用交付的問題：錯盤、重抽、資料遺失卻說成功、點擊雙算、主流程卡死、私人文字外傳、匯入造成執行腳本。不阻擋私人操作測試但須標記：內容尚未專家審校、缺某些真機、尚無完整成就技法。

公開宣稱「完整傳統解卦」前必須另開範圍：鎖定成就規則版本、完整案例測試、專家內容審校。這不是本版的完成條件；本版應以「基礎象徵解讀測試版」對外說明。
