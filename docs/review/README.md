# 專家審校材料

給 1–2 位有實際地占經驗的審校者使用（[PILOT](../PILOT.md) §1）。這裡的文字全部是本產品的編輯草稿；審校完成前，畫面一律標示「內容草稿，未經專家審校」。

| 檔案 | 內容 |
|---|---|
| `expert-review.csv` | 每一列是一個可以單獨審的詞句：十六象的譯名、關鍵詞、反思提示、落宮傾向、行星，十二宮名稱與反思問題，成事與相位用語，學習區說明。用 Excel 或 Google 試算表開啟。 |
| `samples.md` | 9 張盤的完整基礎解讀與進階解讀，涵蓋每一種句型：教學例題、四種成事、不成事、停止盤、關係主題、一般反思。 |

## 怎麼填

每一列的右側六欄由審校者填寫（SPEC §9 要求記錄審核者、日期、來源與修改理由）：

1. **審校結果**：保留／修改／刪除／待討論。
2. **建議文字**：選「修改」時填。
3. **依據來源**：書名與頁碼，或網址。沒有出處、只是實務經驗也可以，請註明「實務經驗」。
4. **理由**、**審校者**、**日期**。

整段句型的意見（例如「成事的結論句太保守」）填在 `S-basic` 或 `S-advanced` 列，註明是 samples.md 的第幾盤哪一段。流派差異（例如左右證人的解釋、Golden Dawn 入宮）請在理由欄寫明採用哪一派。

## 收回之後

依 [ENGINE-AND-DATA §10](../ENGINE-AND-DATA.md) 新增內容版本，已保存的舊記錄不受影響；每一項修改記到 DECISIONS，並寫明審校者。全部條目都經確認後，`reviewStatus` 才能改為 `expert-reviewed`。

文字修改後執行 `npm run review-sheet` 重新產生這兩個檔案（會覆寫，請先把審校者填好的版本另存）。
